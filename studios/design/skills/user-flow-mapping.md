# Skill: User Flow Mapping

## Objective
Translate product requirements and personas into deterministic, state-complete user flows prior to wireframe generation.

## Required Outputs
1. **Primary Actors & Entry Points**: Deep link, command palette, or Agent Dock triggers.
2. **Happy-Path State Graph**: Explicit step sequence (`entry -> intent -> validation -> commit -> confirmation`).
3. **Resilience States**: Empty state CTA, optimistic/pending progress feedback, and recoverable error branches.
4. **Handoff Touchpoints**: State contracts consumed downstream by Architecture and Development Studios.
