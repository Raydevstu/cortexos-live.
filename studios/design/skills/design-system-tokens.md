# Skill: Design System Tokens

## Objective
Standardize semantic visual tokens and accessible component contracts across the product surface.

## Token Categories
- **Color Roles**: `--surface-canvas`, `--surface-elevated`, `--surface-recessed`, `--ink-primary`, `--ink-secondary`, `--accent-primary`, `--border-subtle`, `--border-focus`.
- **Typography Scale**: Display, Heading (`h1`–`h3`), Body, Monospace (`font-mono`), Caption.
- **Spacing & Geometry**: `4px` scale (`space-1`..`space-16`), corner radii (`sm`, `md`, `lg`, `xl`), and hairline border rules.
- **Motion**: Crisp state transitions (`140ms–240ms`, `cubic-bezier(0.22, 1, 0.36, 1)`) honoring `prefers-reduced-motion`.
