# Skill: Wireframe Composition

## Objective
Produce clean, responsive spatial layouts with unambiguous hierarchy and explicit interactive states.

## Composition Rules
1. **Spatial Grid**: 12-column desktop (`>=1280px`), 8-column tablet (`768px–1279px`), 4-column mobile (`<768px`) on a `4px` spacing baseline.
2. **Single Primary Focal Region**: Keep top-level chrome minimal; ensure primary workspace content occupies >= 70% of the viewport canvas.
3. **Interactive State Coverage**: Specify `default`, `loading`, `empty`, `error`, and `disabled` behaviors for every region.
